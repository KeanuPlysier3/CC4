# Start guide

## concept:
This project makes it so you can play a basketball clicker game remotely via your phone. You can play with buttons, or you can use your voice just like a real coach. You choose to either shoot 2pt or 3pt shots. Withing the givin 24s you have to beat the target score to advance. After doing this 3times you see the end screen.

This file helps you setup the experience.

### steps:
- Make sure that you have you local.crt and local.key.
- If you want to use your microphone, make sure you allow your browser to use it in your browser's app settings.
- If you want to quickly win, you can set all things in your localstorage from "rookie" to "elite".
- Make sure to have the .env file, look at the example provided.
- Open the terminal of the project folder, and run: "npm run start".
